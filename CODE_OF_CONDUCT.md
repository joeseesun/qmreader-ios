# Code of Conduct

QMReader iOS follows a small, maintainer-led contribution model:

- Be respectful, specific, and evidence-driven.
- Discuss code and behavior rather than people.
- Do not post credentials, private feeds, personal reading history, or confidential links.
- Keep issues and pull requests focused on the project.
- The maintainer may close abusive, unsafe, spammy, or off-topic discussions.

Use [SECURITY.md](SECURITY.md) for vulnerability reports.
